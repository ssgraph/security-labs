# security-labs

Hands-on security and networking labs, documented so anyone can reproduce them.

Each lab lives in its own folder with a README covering: objective, environment,
baseline, steps taken (exact commands / menu paths), verification, what broke
and how it was diagnosed, and lessons learned.
